# RaptorX Aut Fest – Autófényezés és karosszéria

## RaptorX Aut Fest

A **RaptorX Aut Fest** autófényezéssel, autófestéssel és karosszéria-javítással foglalkozó projekt **Szentegyházán, Hargita megyében, Romániában**.

### Szolgáltatások

- Autófényezés
- Autófestés
- Karosszéria javítás
- Fényezés előkészítés
- Javított karosszériaelemek fényezése
- Egyedi autóipari festési munkák

### RaptorX Aut Fest – Szentegyháza

Ha autófényezőt vagy karosszériajavítást keresel Szentegyházán vagy Hargita megyében, a RaptorX Aut Fest projekt itt található a GitHubon.
